# Resolução de Sistemas Lineares
Este projeto foi desenvolvido para um trabalho da faculdade no curso de Engenharia da Computação, feito por um grupo de quatro pessoas. 
O objetivo é criar um programa capaz de resolver sistemas lineares de até 10x10 usando o método de escalonamento.

*O que o programa faz?*
O programa ajuda a resolver sistemas lineares de forma automática. Ele recebe um sistema de equações, organiza os coeficientes, aplica o método de escalonamento e mostra o resultado para o usuário.

*Funcionalidades principais:*
✅ _Permite inserir sistemas de até 10 equações e 10 variáveis._
✅ _Exibe o sistema original antes do cálculo._
✅ _Usa o método de escalonamento para resolver o sistema._
✅ _Mostra o sistema escalonado e a solução final._
✅ _Identifica se o sistema tem uma única solução, infinitas soluções ou se é impossível de resolver._

*Como usar?*
*1.Rodando o programa*
_.Execute o código na linguagem escolhida pelo grupo._
_.O programa vai pedir o número de equações e variáveis._

*2.Inserindo os dados*
_.Digite os coeficientes das equações e os termos independentes._

*3.Vendo os resultados*
_.O programa mostra o sistema original, a versão escalonada e a solução encontrada._
_.Se não houver solução única, ele avisa se há infinitas soluções ou se o sistema é impossível._

*Requisitos*
_.Linguagem de programação: A escolha fica a critério do grupo._
_.Limitação: O programa suporta sistemas de até 10x10._
